# Afnan Barind Agricultural Technology & Resilience Dashboard

This is the **flat GitHub-upload version**: there are no required folders.

## Upload to GitHub

Upload every file in this folder directly to the repository root.

The repository root should contain:

- `app.py`
- `requirements.txt`
- `README.md`
- `MANIFEST.json`
- `v02_monthly_panel.csv`
- `v01_bmda_t_panel.csv`
- `v01_warpo_baseline.csv`
- `v01_scorecard.csv`
- `v01_bbs_productivity_context.csv`
- `v01_monthly_climate_reference.csv`
- `modis_interpolation_audit.csv`
- `modis_qa_comparison_audit.csv`
- `upazila_locations.csv`

No `data/` folder and no `.streamlit/` folder are required in this version.

## Deploy on Streamlit Community Cloud

1. Create/open your GitHub repository.
2. Upload all the files above into the repository root.
3. Commit the changes.
4. Open Streamlit Community Cloud.
5. Create a new app from the repository.
6. Main file path: `app.py`
7. Deploy.

No API key, database, Earth Engine connection, or secrets are required.
